# Design decisions

FleetGym records every non-obvious decision as an architecture decision record (ADR) in
[docs/adr](https://github.com/moda707/fleetgym/tree/main/docs/adr): the simulator's semantics, the
validator, the recourse conventions, dynamic requests, the multi-agent API, the baselines and the
training stack. The full design document is
[docs/DESIGN.md](https://github.com/moda707/fleetgym/blob/main/docs/DESIGN.md).
